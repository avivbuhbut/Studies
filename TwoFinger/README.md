# TwoFinger

Android quick-actions overlay triggered by a global two-finger hold.

Android 13+ uses `TouchInteractionController` for the custom global hold gesture. Android 12 falls back to Android's two-finger double-tap-and-hold accessibility gesture.

Built-in actions: screen recording, screenshot, Back, Home, Recents, Notifications, Quick Settings and flashlight. Launcher apps can also be selected for the menu.

Screen recordings save to `Movies/TwoFinger`; screenshots save to `Pictures/TwoFinger`.

This is a sideload build. Accessibility services have powerful system-level access, so install only builds you trust.
